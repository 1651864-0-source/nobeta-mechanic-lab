# Spellflow Navigator 🧙‍♀️

**A Companion Intelligence System for Mastering the Arcane Dance of Combat**

Welcome to **Spellflow Navigator**, a reimagined toolkit born from the same creative soil as NobetaTrainer. Where its predecessor focused on raw mechanical dissection, this project seeks to become your **strategic cartographer**—mapping the hidden currents of combat flow, enemy behavior, and environmental interaction in real time. Think of it as a **live conductor’s score** for the symphony of spellcasting, offering not just data, but **readable insights** that transform chaotic skirmishes into choreographed performances.

---

## 🌟 Why Another Tool? Because Knowledge Should Flow Like Mana

The original trainer concept proved that deep-game-analysis tools have immense value. Spellflow Navigator takes that philosophy further: it doesn't just reveal numbers—it reveals **patterns**. It’s built for two audiences: the **speedrunner** seeking frame-perfect consistency and the **curious explorer** who wants to understand *why* the game behaves the way it does under the hood.

Our tool functions as a **non-invasive observer**, sitting quietly in the background, reading memory state and rendering visual overlays that feel like native game UI. No modification to the game files, no online interference—just pure, localized intelligence gathering.

---

## 🚀 Core Capabilities (Feature Matrix)

| Feature | Description | Benefit |
|---------|-------------|---------|
| **Live Hitbox Visualization** | Renders attack/displacement zones for player and mobs | Understand spatial thresholds without trial-and-error |
| **Timeline Scrubber** | Replays recorded combat segments frame-by-frame | Study input windows and animation cancels |
| **Cooldown Symmetry Mapper** | Visualizes ability recovery relative to animation states | Optimize rotations for maximum DPS windows |
| **Environment Collision Heatmap** | Tracks where dodges/wall-bounces occur most | Identify glitch spots and safe zones for speed paths |
| **AI Aggro Radar** | Displays enemy detection cones and transition thresholds | Plan multi-target engagements with precision |
| **Seed/Frame Analyzer** | Extracts RNG values affecting drop rates or attack patterns | Predict loot outcomes or attack sequences (for research) |

Each feature is designed to answer a specific question you didn’t know you had, turning the **opaque** into the **transparent**.

## 🧩 The Interface Paradigm

We believe tools should be **invisible until needed**. The UI is a **floating, low-opacity overlay** that respects your focus. It supports:

- **Dark-Adaptive Theme**: Automatically dims when your game screen gets darker (mana-intensive battles).
- **Modular Panels**: Drag, resize, and pin only what matters for your current run.
- **Session Snapshotting**: Save your entire analysis state as a portable project file, shareable with peers.

No clutter, just **intelligent presence**.

## 🛠️ Customization and Extensibility

You aren’t locked into our vision. The entire overlay system is built on a **plugin architecture**. If you want a specific stat tracked (like "distance from boss center during third combo"), you can write a simple configuration JSON to add it. For advanced users, a Python-like scripting interface (embedded, no external dependencies) allows custom logic triggers.

*Example Use Case*: Create a visual pulse that syncs with your character’s invincibility frames during a specific dodge. Color intensity changes as the window closes. This is the kind of creative feedback the tool empowers.
